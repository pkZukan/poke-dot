# poke-dot
Pokemon ZA asset file support for Godot

## Screenshot
![godot](https://i.imgur.com/5L7Uw4y.png)

## Usage
1. Dump asset files somewhere in your project folder
2. Copy over the gflib folder from this repo into the root of your project
3. Go into Project Settings -> Gflib -> Romfs Root and set the asset folder
